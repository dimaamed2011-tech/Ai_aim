# AI AIM

> Локальный проект по компьютерному зрению: анализ изображения с экрана в реальном времени, детекция объектов нейросетью и вывод оверлея поверх рабочего стола.

## Что это

AI AIM — настольная утилита для Windows, которая в реальном времени захватывает
изображение области экрана вокруг прицела, распознаёт на нём людей нейросетью
YOLOv8n и показывает результат оверлеем. Дополнительно умеет вести мышь к
найденной цели.

Ключевое отличие от «внутренних» решений: программа **не читает память игры,
не внедряется в процессы и не подменяет файлы игры** — это внешний анализатор
картинки, работающий поверх обычного скриншота.

```
AI_Aim.exe        готовый самодостаточный файл (58,5 МБ): модель, иконка
                          и все библиотеки внутри.
AI_Aim_data      настройки (создаётся сама, сохраняется автоматически).
```

## Важно

- Проект **не читает память процессов**, не инжектит код и не модифицирует файлы
  игр — работает только с изображением экрана.
- При этом программа **отправляет синтетические события мыши** (`SendInput`)
  и тем самым влияет на управление в приложении, которое сейчас в фокусе.
- В онлайн-матчах использование подобных инструментов нарушает правила игр и
  EULA: в CS2 это приводит к блокировке VAC, в Rust — к персональному бану на
  серверах. Онлайн-игры для этого инструмента не предназначены.
- Автор не несёт ответственности за блокировки аккаунтов, баны и иные
  последствия, возникшие при нарушении правил игр или законодательства.
- Дисклеймер не является юридической консультацией и не гарантирует освобождение
  от ответственности.

## Возможности

- Детекция людей по изображению с экрана (YOLOv8n, класс `person`).
- Оверлей с рамками объектов, уголками и процентом уверенности.
- Трекер между кадрами (IoU + сглаживание) — рамки не мигают.
- Выбор цели по близости к прицелу в пределах радиуса FOV.
- Ведение мыши к точке **внутри** рамки (не в центр): смещение по осям,
  ограничение скорости, лёгкое случайное отклонение.
- Круг FOV вокруг прицела.
- Подсветка краёв экрана, пока цель в кадре.
- Назначение клавиши активации на любую клавишу, включая дополнительные кнопки
  мыши (4/5).
- Две модели (320 px точнее / 256 px быстрее) — выбор автоматический.
- Портaтивность: настройки рядом с программой, всё внутри одного файла.
- Автосохранение настроек.

## Требования

- Windows 10/11 x64. Для готового EXE ничего доустанавливать не нужно.
- Для сборки из исходников: Python 3.9+, `pip`, пакеты `pyinstaller`, `mss`,
  `onnxruntime`, `numpy`, `pillow`.

## Использование

| Клавиша | Действие |
|---|---|
| `Right Shift` | показать / скрыть меню |
| `Insert` | то же (запасная) |
| `End` | завершить работу |
| клавиша активации (по умолчанию `ПКМ`) | удерживать для работы наведения |

Клавишу активации задают кнопкой **«НАЗНАЧИТЬ»** или из списка: ЛКМ, ПКМ,
дополнительные кнопки мыши, буквы, цифры, F1–F12, numpad, стрелки, служебные.

## Производительность

| Режим | Инференс | FPS |
|---|---|---|
| 320 px | ~50 мс | ~20 |
| 256 px | ~19–29 мс | ~35–57 |

Захват экрана и инференс идут параллельно (конвейер) — это даёт примерно
полтора раза к последовательной обработке.

## Ограничения

- Модель COCO ищет **реалистичных людей**: в CS2 и Rust работает, аватары
  Roblox распознаются плохо, для них нужна своя модель.
- При области захвата свыше ~500 px мелкие цели теряются.
- Оверлей — прозрачное окно поверх всех; при сбое прозрачности программа
  восстанавливает её сама, помогает перезапуск.
